Art gallery update.

Hello folks! I worked hard for this update, mostly because I was trying to do some things that I haven't done before. If you know about the "So you want the be a pilot" kind of thing, that's what I'm refering to.

Changelog

  • Added the Art Gallery, where drawings are organized in albums that have a date of the most recent drawing, tags and mediums
  • Added a simple sort menu for dates, and a filter system for mediums and tags in the Art Gallery
  • Drawings are loaded via Javascript and JSON files containing all information required
  • Stored the images in an R2 cloudflare bucket
  • More media queries for a better mobile experience
  • Fixed a bug in the modal view on mobile

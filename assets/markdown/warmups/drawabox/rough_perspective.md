Divide the page in 3 rectangles using a ruler. Then, on each frame, draw an horizon line and one vanishing point to the center. On each frame, draw a rectangle, place the back corners, following the vanishing point.
Finally, construct all of the edges of the box. Repeat this process 4-5 times per frame. Once the page is filled, check if your convergences are correct by extending either the edges or the corners. For detailed instructions, click [here](https://drawabox.com/lesson/1/roughperspective).

# Goal

The goal of this exercise is to separate students from the explicit reliance of plotting back to the vanishing points, and getting used to the fact that parallel lines converge.
